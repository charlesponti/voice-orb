# The Voice Orb

Interactive explainer of a voice-reactive orb of dots, plus a reusable `<voice-orb>` web component.

## Use the web component anywhere

```html
<script src="https://charlesponti.github.io/voice-orb/voice-orb.js" type="module"></script>
<voice-orb dots="1800" gain="0.5" spin="0.12" style="width:360px;height:360px"></voice-orb>
```

Attributes: `dots`, `gain`, `spin`, `colorby` (`age`|`pitch`), `mode` (`spectrum`|`loudness`|`naive`), `width`, `height`.

Live demo: https://charlesponti.github.io/voice-orb/
